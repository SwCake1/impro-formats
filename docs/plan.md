## Сейчас

Перенести очищенный [Code.js](../scripts/apps-script/Code.js) в Google Apps Script.
Затем подключить чтение «Опубликовано» к сборке сайта. Доступ технического аккаунта
проверен: 269 форматов, 269 уникальных id. Учётные данные Vercel пока не настроены.

## Договорённости

- Идём по одному шагу: объяснение → действие → проверка.
- Сборка Vercel читает одобренный снимок напрямую через Sheets API и технический аккаунт.
  Права аккаунта выдаются на весь документ; лист «Опубликовано» выбирает код сборки.
- Apps Script отвечает за `Publish`, фиксацию снимка, запуск сборки и выдачу `id`.
- Правки рабочих ячеек не запускают публикацию. На `Publish`: проверка → снимок → сборка.
- «Опубликовано» содержит копию значений, а не формулы со ссылками на черновики.
  Все сборки, включая запущенные изменениями кода, читают только этот снимок.
- `id` хранится в первой колонке и не меняется при переименовании.
- Файл `public/data/formats.json` — временный этап; получение одобренного каталога при сборке ещё предстоит.
- Учётные данные Google храним в среде сборки Vercel, адрес Deploy Hook — в свойствах Apps Script.
  Посетителям доступен готовый каталог.
- Упаковка усложняет копирование каталога, но не делает опубликованные данные приватными.
- «Видео» — многострочное поле с несколькими ссылками и пояснениями.
