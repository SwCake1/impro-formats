# Разработка инструментов

Инструменты разрабатываются в `public/tools/<имя>/` и публикуются вместе с порталом.
Их HTML, CSS, JavaScript, данные, изображения, звуки и лицензии шрифтов уже перенесены
из `impro-toys`. Vite включает их в обе сборки сайта.

## Данные

| Инструмент | Файл внутри `public/tools/` |
| --- | --- |
| Звонок | Определения звуков в `bell/index.html`, ресурсы в `bell/Assets/` |
| Слова | Массив `WORDS` в `word/app.js` |
| Буквы | Алфавит и группы букв в `letters/app.js` |
| Эмоции | Группы эмоций в `emotion/app.js` |
| Темы батлов | `rap-battle/topics.js` |
| Локации | `locations/locations.js`, текстовая подборка в `locations/locations.txt` |
| Отношения | `relationship/relationships.js` |
| Первая реплика | `first-line/lines.js` |
| Жанры | `genres/genres.js`, кадры в `genres/stills/` |
| Профессии | `professions/professions.js` |
| Персонажи | `characters/characters.js` |

JSONL-файлов в исходном проекте нет.

## Добавление инструмента

1. Создай папку в `public/tools/` с собственной страницей, оформлением и данными.
2. Подключи шапку по образцу существующего инструмента. Укажи
   `data-portal-root="../../"` и `data-portal-tool` с именем новой папки.
3. Добавь пункт с названием и контурной иконкой в `public/portal/navigation.js`.
   Единый переключатель в шапке открывает каталог форматов и все инструменты.
   На главной кнопка называется «Инструменты», внутри инструмента — по его названию.
   Переходы ведут прямо в инструмент.
4. Добавь карточку в `public/tools/index.html`, иконку в
   `public/tools/shared/assets/` и инструмент в проверки `tests/browser/portal.spec.ts`.
5. Проверь инструмент и каталог на широком и мобильном экранах, включая
   клавиатуру, быстрые нажатия, настройки и возврат к форматам.

Общие стили шапки находятся в `public/portal/styles.css`.
Шапка обрабатывает свои клики и клавиши внутри себя, чтобы глобальные действия
инструмента срабатывали в его рабочей области.
Отдельная страница `public/tools/index.html` доступна по прямому адресу.

Для локальной разработки используй `npm run dev:cached`.
Проверки проекта — `npm test`, `npm run build` и `npm run test:browser`.
