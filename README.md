# Что сыграем?

Статический каталог импровизационных форматов. При открытии страницы сайт загружает `public/data/formats.json` — снимок собственной приватной Google-таблицы. Последний успешный набор сохраняется локально на случай сетевой ошибки.

## Данные

Снимок содержит 269 форматов на момент переноса. Используются постоянные идентификаторы из первой колонки `id`; переименование формата не меняет его ссылку.

Порядок полей таблицы: `id`, название, описание, модератор, зритель на сцене, реквизит, мебель, дополнительно, теги. Колонка `Видео` пока не импортируется и не отображается.

JSON содержит `schemaVersion: 2`, дату `generatedAt` и массив `records`. У каждой записи есть `id`, `title`, `description`, `moderator`, `audienceOnStage`, `props`, `furniture`, `note`, `tags`. Пустые признаки сохраняются как `null`. Параметры поиска и мебели вычисляются из текста при загрузке.

Сейчас это зафиксированный снимок: изменения Google-таблицы сами по себе сайт не обновляют. Для публикации новых данных нужно обновить `public/data/formats.json`, проверить и пересобрать сайт. Авторизованное чтение таблицы во время сборки и автоматический запуск публикации будут подключены отдельно.

В клиентской сборке нет адреса таблицы или ключей доступа. Готовый JSON каталога доступен посетителям сайта.

## Локальный запуск

```bash
npm install
npm run dev
```

Проверки:

```bash
npm test
npm run build
```

## Фильтры

На широком экране фильтры расположены в компактной боковой панели с регулируемой шириной. Особенности и условия можно свернуть. На телефоне панель раскрывается над списком; кнопка «Показать N форматов» возвращает к результатам.

Выбранные ограничения видны над результатами и снимаются по одному. Поиск и фильтры сохраняются в URL.

## GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` собирает и публикует `dist` при push в `main`. В настройках отдельного GitHub-репозитория выберите **Settings → Pages → Source → GitHub Actions**.

Проект использует относительный `base`, поэтому работает и на корневом домене, и по адресу вида `username.github.io/repository/`.
