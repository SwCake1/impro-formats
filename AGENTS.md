# Impro Formats

Статический каталог на Vite + TypeScript. Браузер читает `data/formats.json` со своего сайта.

Актуальная схема перехода и прогресс — в `docs/plan.md`; обновлять его после выполненных шагов. Схема: ручной `Publish` в Apps Script → снимок значений на листе «Опубликовано» → чтение через Sheets API при сборке Vercel.

`npm run build:published` получает и проверяет одобренный снимок, собирает сайт и записывает публичные данные в `dist`. Настройки — серверные переменные `GOOGLE_SHEET_ID` и `GOOGLE_SERVICE_ACCOUNT_JSON` либо локальный путь `GOOGLE_APPLICATION_CREDENTIALS`. Ошибки импорта останавливают сборку. Обычная `npm run build` пока использует фиксированный `public/data/formats.json` для GitHub Pages. Команда сборки Vercel и HTTP-кэш заданы в `vercel.json`; сам проект Vercel ещё не подключён.

Каталог — обычный JSON. Браузер сразу показывает проверенный локальный кэш, затем проверяет HTTP-кэш у сервера. Совпавший ETag позволяет повторно использовать записи. Ошибка сети, новых данных или хранилища не должна удалять рабочий каталог.

Локальные учётные данные могут находиться в `ignore/`: папка исключена из Git и закрыта для сервера Vite. Ключи не должны попадать в клиентский код, `public/` или коммиты.

## Правила

- Не редактировать исходную Google-таблицу.
- Использовать постоянные `id` из первой колонки таблицы, не вычислять их из названия или описания.
- Сохранять `base: './'`, чтобы сайт работал в подпапке GitHub Pages.
- Данные таблицы выводить только как текст, без небезопасного HTML.
- Пустые признаки считать неизвестными, а не отрицательными.
- Интерфейс должен работать с клавиатуры и на мобильных экранах.
