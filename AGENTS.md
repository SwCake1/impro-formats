# Impro Formats

Статический каталог на Vite + TypeScript. Данные читаются в браузере из `public/data/formats.json` — снимка собственной приватной Google-таблицы. Автоматическое обновление пока не подключено; бэкенда и секретных ключей в проекте нет.

## Правила

- Не редактировать исходную Google-таблицу.
- Использовать постоянные `id` из первой колонки таблицы, не вычислять их из названия или описания.
- Сохранять `base: './'`, чтобы сайт работал в подпапке GitHub Pages.
- Данные таблицы выводить только как текст, без небезопасного HTML.
- Пустые признаки считать неизвестными, а не отрицательными.
- Интерфейс должен работать с клавиатуры и на мобильных экранах.
