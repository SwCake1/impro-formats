# Proposal

## Why

Собранные агентом форматы нужно просмотреть и поправить перед переносом в каталог. Сейчас нет небольшого готового инструмента, в котором можно открыть одну партию, выбрать подходящие записи и скопировать результат для таблицы или обратно агенту.

## What Changes

- Добавить постоянный HTML-шаблон и локальную команду, которая заполняет его структурированными данными агента и создаёт один автономный файл для ревью партии.
- Показывать редактируемые поля каталога, галочку выбора, источник и подсказки о похожих форматах. Рекомендации агента задают начальный выбор и предлагаемые обновления; без рекомендаций записи не выбраны. Пользователь может изменить решение.
- Добавить кнопки «Скопировать для таблицы» и «Скопировать для агента». Обе используют только выбранные записи с текущими правками.
- Для полного снимка совпадения добавить режим обновления с видимыми полями находки и отдельным переносом: видео и теги дополняют итог, остальные поля явно заменяются. Обновления передаются агенту как изменения до/после, в таблицу копируются только новые форматы.
- Выгружать строки в порядке колонок A–L, включая видео, с пустым постоянным `id`; сохранять неизвестные признаки отдельно от отрицательных.
- Описать формат входного JSON и короткий сценарий подготовки партии агентом. Реальные партии и готовые HTML хранить вне публичной сборки.
- Предзаполнять требования по механике, оставляя неизвестным неоднозначное; не добавлять общую продолжительность в заметки. Поддержать C/S для карточки под курсором и регулируемую ширину с максимумом по умолчанию на 15% меньше прежнего.

## Capabilities

### New Capabilities

- `format-review`: автономное ревью партии предложенных форматов, отображение источников и переданных агентом совпадений, редактирование, выбор и копирование результата.

### Modified Capabilities

Нет.

## Impact

- Новый локальный инструмент в `tools/format-review/`, генератор и вспомогательная логика в `scripts/`, команда в `package.json`, документация и вымышленный пример партии.
- Проверки преобразования данных и браузерные сценарии на существующих Vitest и Playwright; новые внешние зависимости не требуются.
- Публичный каталог, JSON версии 3, чтение Google Sheets и Apps Script Publish сохраняют текущее поведение. Инструмент не подключается к таблице и не записывает в неё.
- Сбор из Telegram и семантическое сравнение выполняет агент до генерации HTML по инструкциям отдельного скилла. Пользовательские формы, приём пользовательских предложений видео и серверная очередь не входят в эту версию.
