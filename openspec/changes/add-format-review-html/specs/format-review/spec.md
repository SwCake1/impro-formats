# Spec Delta

## Purpose

Позволяет просмотреть одну подготовленную агентом партию форматов, исправить поля и выбрать записи для переноса. Сохраняет связь с источниками и подсказками о совпадениях при передаче результата обратно агенту.

## ADDED Requirements

### Requirement: Generate a standalone review file
Инструмент MUST принимать JSON партии по документированной версионированной схеме и создавать автономный HTML, открываемый как локальный файл без сервера и автоматических сетевых запросов. Некорректные данные MUST приводить к понятной ошибке без создания или перезаписи результата.

#### Scenario: Open a prepared batch locally
- **WHEN** агент генерирует HTML из корректной партии и пользователь открывает файл без сети
- **THEN** отображаются все кандидаты и доступны редактирование, выбор и подготовка обеих выгрузок

#### Scenario: Reject invalid input
- **WHEN** JSON содержит неподдерживаемую версию, повторяющиеся идентификаторы кандидатов или поля неверного типа
- **THEN** генерация завершается с ошибкой, указывающей проблемное поле, а существующий выходной файл остаётся прежним

#### Scenario: Review an empty batch
- **WHEN** партия не содержит кандидатов
- **THEN** HTML сообщает, что форматов нет, и не предлагает копирование пустого результата

### Requirement: Edit catalog fields without changing unknown values
Редактор MUST позволять менять название, описание, признаки модератора, зрителя на сцене и реквизита, мебель, дополнительно, форму, особенности и подборки. Признаки MUST различать «Да», «Нет» и «Неизвестно». Правки MUST сохраняться в течение открытого сеанса при переходе между кандидатами.

#### Scenario: Edit several candidates
- **WHEN** пользователь меняет текст и классификацию одного кандидата, открывает другого и возвращается
- **THEN** отображаются внесённые правки, включая переносы строк и изменённые списки

#### Scenario: Preserve an unknown flag
- **WHEN** у кандидата признак имеет значение null и пользователь его не меняет
- **THEN** редактор показывает «Неизвестно», а экспорт сохраняет неизвестное значение

### Requirement: Explicitly select candidates for export
Все кандидаты MUST изначально быть не выбраны. Пользователь MUST иметь возможность независимо выбирать и снимать выбор с каждой записи и видеть число выбранных. Обе выгрузки MUST содержать только выбранные записи в порядке исходной партии.

#### Scenario: Export a subset
- **WHEN** пользователь выбирает второй и четвёртый форматы, а затем снимает выбор со второго
- **THEN** счётчик показывает одну запись и обе выгрузки включают только четвёртый формат

#### Scenario: Empty selection
- **WHEN** не выбран ни один формат
- **THEN** кнопки копирования недоступны и буфер обмена не изменяется

### Requirement: Display source and supplied similarities
Карточка MUST показывать источник и необязательные совпадения, переданные агентом: существующий id, название, описание и объяснение сходства. Подсказки MUST быть доступны без сети и не менять выбор пользователя. Отсутствие подсказок MUST NOT выдаваться за подтверждённое отсутствие дублей.

#### Scenario: Inspect a possible duplicate
- **WHEN** для кандидата переданы два похожих формата
- **THEN** пользователь может прочитать оба описания и объяснения, продолжить редактирование и независимо выбрать или пропустить кандидата

#### Scenario: Similarities were not supplied
- **WHEN** агент не передал похожие форматы или передал пустой список
- **THEN** интерфейс сообщает об отсутствии переданных подсказок, не утверждая, что проверка дублей успешно пройдена

### Requirement: Copy spreadsheet rows in the catalog column order
Кнопка «Скопировать для таблицы» MUST готовить строки без заголовка в порядке A–K действующего каталога с пустой колонкой id. Булевы значения MUST экспортироваться как TRUE/FALSE, неизвестные как пустые ячейки, списки как значения через запятую. Спецсимволы MUST сохранять границы ячеек, а текст MUST NOT становиться формулой при вставке.

#### Scenario: Paste selected new formats
- **WHEN** пользователь копирует два выбранных формата для таблицы
- **THEN** подготовлены две строки по 11 ячеек: id, название, описание, модератор, зритель на сцене, реквизит, мебель, дополнительно, форма, особенности, подборки
- **AND** обе ячейки id пусты, а id похожих существующих форматов не попадают в новые строки

#### Scenario: Preserve complex text during spreadsheet transfer
- **WHEN** описание содержит кавычки, табуляцию и перенос строки, а текстовое поле начинается со знака формулы
- **THEN** вставка в поддерживаемую таблицу сохраняет одну запись и правильные колонки, а текстовое поле интерпретируется как текст

### Requirement: Copy edited selections for an agent
Кнопка «Скопировать для агента» MUST готовить JSON по документированной версионированной схеме. Он MUST включать идентификатор партии, выбранных кандидатов с текущими полями, их внутренние идентификаторы, источники и переданные совпадения. Значения признаков и списков MUST сохранять типы; постоянные id новых форматов MUST NOT назначаться.

#### Scenario: Return edited candidates to the agent
- **WHEN** пользователь изменил название, описание и неизвестный признак выбранного формата и копирует результат для агента
- **THEN** JSON содержит новые значения и исходные сведения об источнике и совпадениях, не содержит невыбранных кандидатов и не объявляет записи добавленными в таблицу

### Requirement: Validate selected records before copying
Выбранный формат MUST иметь непустое название. Если выбранная запись некорректна, обе операции копирования MUST указывать ошибку у её поля и сохранять прежний буфер обмена. Некорректное название невыбранного черновика MUST NOT препятствовать выгрузке остальных выбранных записей.

#### Scenario: Fix an empty title
- **WHEN** пользователь очищает название выбранного формата и нажимает кнопку копирования
- **THEN** интерфейс указывает на пустое название и не сообщает об успешном копировании
- **AND** после исправления названия копирование становится доступно

### Requirement: Provide an honest clipboard fallback
Инструмент MUST сообщать об успехе только после подтверждённого копирования. При недоступном или отклонённом доступе к буферу MUST оставаться возможность вручную скопировать подготовленную выгрузку из доступного текстового поля без потери правок и выбора.

#### Scenario: Clipboard access is denied for a local file
- **WHEN** браузер отклоняет автоматическое копирование
- **THEN** пользователь получает объяснение и текст выбранной выгрузки для ручного копирования, а редактор сохраняет текущее состояние

### Requirement: Treat supplied content as text
Названия, описания, источники и объяснения совпадений MUST отображаться как текст. Встроенные данные MUST NOT изменять структуру HTML или выполнять код. Ссылки MUST быть активными только для разрешённых HTTP/HTTPS-адресов; остальные значения доступны как текст.

#### Scenario: Source contains markup and a script terminator
- **WHEN** входное описание содержит HTML, закрывающий тег script и обработчики событий, а ссылка имеет схему javascript
- **THEN** текст отображается буквально, код не выполняется, опасная ссылка неактивна и остальные кандидаты остаются доступны

### Requirement: Keep review usable on keyboard and mobile
Выбор, редактирование и обе операции копирования MUST быть доступны с клавиатуры с видимым фокусом и подписями полей. На мобильном экране MUST быть доступны все поля, подсказки и кнопки без горизонтальной прокрутки страницы.

#### Scenario: Review using only a keyboard
- **WHEN** пользователь перемещается клавишей Tab, выбирает запись и редактирует её поля
- **THEN** порядок фокуса позволяет дойти до обеих кнопок копирования и выгрузить выбранное без мыши

#### Scenario: Open on a narrow screen
- **WHEN** ширина экрана составляет 390 пикселей
- **THEN** карточки, поля и совпадения читаемы, а кнопки доступны без горизонтальной прокрутки страницы

### Requirement: Keep review separate from publication
Инструмент MUST работать с подготовленными данными без подключения к Google Sheets, Telegram или сервису ИИ. Генерация MUST NOT помещать партии в public или dist проекта. Выбор и копирование MUST NOT запускать запись в таблицу, назначение постоянных id или Publish.

#### Scenario: Prepare a batch without credentials
- **WHEN** агент запускает генератор с корректным входным файлом без ключей Google и доступа к Telegram
- **THEN** HTML создаётся локально вне публичных каталогов, а данные каталога и таблицы не изменяются
